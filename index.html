Is this really Bootstrap 6?
Yes! This demo runs Bootstrap 6.0.0-alpha.1. The theme sits on top of its CSS and uses its native tab, menu, and dialog plugins.
Can I use it on my own site?
Absolutely. Download the theme, load its stylesheet after Bootstrap, and keep the bundled img folder beside the CSS. The code is MIT licensed; original artwork is credited to Divshot.
